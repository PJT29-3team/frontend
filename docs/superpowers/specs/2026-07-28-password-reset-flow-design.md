# 비밀번호 재설정 화면 설계

## 목표

로그인 화면의 `비밀번호 찾기`부터 이메일 요청, 링크 검증, 새 비밀번호 입력, 변경 완료까지 작은둥지 브랜드로 일관된 흐름을 제공한다.

## 화면 흐름

### 1. 이메일 요청

- 공용 작은둥지 헤더와 푸터를 사용한다.
- `이메일 로그인` 뒤로가기, 2단계 진행 표시, `비밀번호 재설정` 제목을 표시한다.
- 이메일 주소를 입력하고 `링크 보내기`를 누른다.
- 잘못된 이메일은 빨간 안내 상자로 표시한다.
- 서버가 요청을 받으면 가입 여부와 관계없이 같은 완료 안내를 표시한다.

### 2. 링크 검증

- 메일의 `새 비밀번호 설정하기`를 누르면 `/auth/password/reset?token=...`으로 이동한다.
- 토큰을 확인하는 동안 작은둥지 헤더 아래에 확인 중 상태를 표시한다.
- 만료·사용·위조 토큰이면 새 링크 요청 버튼을 표시한다.
- 유효하면 새 비밀번호 입력 화면으로 전환한다.

### 3. 새 비밀번호 설정

- 공용 헤더와 푸터, 뒤로가기, 2단계 진행 표시를 사용한다.
- 새 비밀번호와 확인 입력을 제공하고 각각 표시·숨기기 아이콘을 둔다.
- 영문·숫자·특수문자 포함 8자 이상 규칙을 실시간으로 안내한다.
- 두 값의 일치 여부를 실시간으로 안내한다.
- 최근 5개 재사용 오류는 서버 문구를 빨간 안내 상자로 표시한다.
- `변경 완료`는 모든 입력 조건이 맞을 때만 활성화한다.

### 4. 변경 완료

- 작은둥지 브랜드 전용 헤더와 중앙 성공 아이콘을 표시한다.
- `비밀번호가 변경되었습니다`와 새 비밀번호 로그인 안내를 표시한다.
- `로그인으로 돌아가기` 버튼으로 이메일 로그인 화면에 이동한다.

## 마이페이지

현재 비밀번호, 새 비밀번호, 확인 입력을 추가한다. 같은 비밀번호 규칙을 적용하고 변경 성공 시 현재 로그인 정보를 비운 뒤 이메일 로그인 화면으로 이동한다.

## 반응형 및 접근성

- 데스크톱은 기준 이미지처럼 좁은 중앙 폼과 넓은 여백을 사용한다.
- 모바일은 좌우 20px 여백 안에서 입력과 버튼이 가로 스크롤 없이 표시되게 한다.
- 모든 입력은 레이블과 자동완성 속성을 가진다.
- 아이콘 버튼은 화면 읽기용 이름과 키보드 포커스 표시를 가진다.
- 상태와 오류 문구는 `aria-live`로 알린다.

## 검증

- 요청 화면 문구와 중립 응답 테스트
- 토큰 확인 전 입력 미표시 테스트
- 강한 비밀번호와 일치 검증 테스트
- 최근 비밀번호 재사용 서버 오류 표시 테스트
- 완료 화면과 로그인 링크 테스트
- 마이페이지 변경 성공 후 세션 해제 테스트
- 데스크톱과 모바일 시각 검증
