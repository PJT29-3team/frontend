# 로그인 헤더 브랜드 수정 설계

## 목적

로그인 페이지 헤더 왼쪽 브랜드를 기준 이미지와 같은 구성으로 정리한다. 사용자가 제공한 PNG 로고를 그대로 사용하고, 옆에 `집현전` 텍스트와 노란 밑줄을 배치한다. 가운데 로그인 폼과 오른쪽 `고객센터`, `회원가입` 메뉴는 변경하지 않는다.

## 검토한 방식

### 채택: PNG 심볼과 텍스트 분리

제공 PNG를 독립 이미지로 렌더링하고 텍스트와 밑줄은 HTML/CSS로 구성한다. 원본 로고를 변형하지 않으면서 기준 이미지에 맞게 간격과 크기를 조절할 수 있고, 반응형 화면에서도 선명한 텍스트를 유지할 수 있다.

### 제외: 가로형 이미지로 재합성

로고, 텍스트, 밑줄을 하나의 새 이미지로 합치면 구현은 단순하지만 화면 크기에 따라 글자가 흐려질 수 있고 간격 조정이 어렵다.

### 제외: 기존 SVG 내부에 PNG 삽입

기존 SVG 구조를 유지할 수 있지만 래스터 이미지를 SVG에 포함하는 불필요한 복잡성이 생기고 제공 원본과의 대응 관계가 불명확해진다.

## 컴포넌트 변경

`LoginChoiceView`의 기존 가로형 `jiphyeonjeon-logo.svg` 한 장을 다음 세 요소로 교체한다.

1. 제공 PNG 로고
2. `집현전` 텍스트
3. 텍스트 아래의 짧은 노란 밑줄

브랜드 전체는 기존과 같이 홈으로 이동하는 하나의 `RouterLink`로 유지한다. 링크의 접근성 이름은 `집현전 홈`을 유지하고, 이미지 대체 텍스트는 빈 값으로 둬 화면 낭독기가 보이는 텍스트를 중복해서 읽지 않게 한다.

## 시각 규칙

- PNG 원본 비율은 변형하지 않는다.
- 데스크톱에서는 로고를 40px 정사각형 안에 표시한다.
- 로고와 텍스트 사이 간격은 8px로 둔다.
- `집현전`은 현재 서비스의 짙은 갈색 계열과 굵은 글씨를 사용한다.
- 노란 밑줄은 텍스트 폭보다 짧게 왼쪽 정렬한다.
- 모바일에서는 로고와 글자 크기를 소폭 줄이되 브랜드 구조는 유지한다.
- 헤더 높이, 좌우 여백, 오른쪽 메뉴, 본문 위치는 변경하지 않는다.

## 에셋 처리

제공 파일 `/Users/jojinhyeok/Downloads/image 15.png`를 프론트엔드 에셋 디렉터리의 의미 있는 이름으로 복사한다.

```text
src/assets/jiphyeonjeon-header-logo.png
```

기존 `jiphyeonjeon-logo.svg`는 다른 화면에서 사용할 수 있으므로 삭제하지 않는다.

## 테스트 기준

- 로그인 헤더가 새 PNG 에셋을 사용한다.
- 헤더에 정확히 `집현전` 텍스트가 표시된다.
- 브랜드 링크의 접근성 이름은 `집현전 홈`이다.
- 이미지와 텍스트는 동일한 브랜드 링크 안에 있다.
- 가운데 로그인 폼과 오른쪽 메뉴 문구는 기존 테스트를 계속 통과한다.
- 데스크톱과 모바일 화면에서 로고 비율이 유지되고 다른 헤더 요소와 겹치지 않는다.

## 범위 제외

- 로그인 본문과 버튼 스타일 변경
- 오른쪽 보조 메뉴 변경
- 랜딩 페이지와 다른 인증 화면의 로고 교체
- 제공 PNG 자체의 색상 또는 형태 수정
