# 소셜 회원가입 추가정보 화면 설계

## 목표

신규 카카오 로그인 사용자가 메인 화면으로 이동하기 전에 이름과 생년월일을 입력하도록 하고, 제공된 시안과 같은 `작은둥지` 추가정보 화면을 제공한다.

## 범위

- 기존 카카오 콜백의 `profileRequired=true` 분기와 `/social/profile` 라우트는 유지한다.
- 소셜 추가정보 화면에서 이름과 생년월일만 입력받는다.
- 생년월일 입력을 처음 선택하면 `1960-01-01`을 기본값으로 사용한다.
- 제출 시 기존 API 계약에 맞춰 생년월일에서 출생연도만 추출해 전송한다.
- 저장에 성공한 경우에만 메인 화면으로 이동한다.
- 기존 이메일 로그인, 이메일 회원가입, 카카오 이메일 중복 안내 흐름은 변경하지 않는다.

## 화면

- 흰색 전체 화면 상단 왼쪽에 제공된 로고와 `작은둥지` 브랜드를 표시한다.
- 소셜 추가정보 화면에서는 헤더 우측의 고객센터와 회원가입 메뉴를 숨긴다.
- 본문 중앙에 별도 카드 없이 최대 너비 420px의 폼을 둔다.
- 제목은 `몇 가지만 더 확인할게요`로 표시한다.
- 이름 필드의 레이블은 `이름`, 안내 문구는 `이름을 입력해주세요.`로 표시한다.
- 생년월일 필드의 레이블은 `나이`로 표시하며 달력 입력을 사용한다.
- 제출 버튼 문구는 `다음`이고 브랜드 노란색을 사용한다.
- 모바일에서는 좌우 여백을 줄이고 폼 너비를 화면에 맞춘다.

## 데이터 흐름

1. 신규 카카오 사용자가 인증을 마치면 콜백 화면이 `/social/profile`로 이동한다.
2. 사용자가 이름과 생년월일을 입력한다.
3. 화면은 생년월일의 첫 네 자리를 출생연도로 변환한다.
4. `authStore.completeSocialProfile(name, birthYear)`를 호출한다.
5. 성공하면 `/main`으로 이동하고, 실패하면 현재 화면에 서버 오류 문구를 표시한다.

## 검증

- 구성요소 테스트로 브랜드, 정확한 문구, 카드가 없는 레이아웃, 1960 기본값을 확인한다.
- 구성요소 테스트로 이름과 출생연도 제출 및 성공 후 이동을 확인한다.
- 구성요소 테스트로 저장 실패 시 메인으로 이동하지 않고 오류를 표시하는지 확인한다.
- 전체 프런트엔드 테스트와 빌드를 실행한다.
- 데스크톱과 모바일 화면을 브라우저에서 확인한다.
